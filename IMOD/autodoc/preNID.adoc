[Field = Alpha]
short = a
type = FA
usage = Alpha, typical values from 0.2 to 0.5
tooltip = 
manpage = Alpha, the fraction of the initial sigma used as the sigma of a
Gaussian for smoothing the difference between the initially smoothed and
original image.  Typical values are 0.2 to 0.5; default is 0.5.

[Field = Beta]
short = b
type = FA
usage = Sigma beta (in pixels),  typical values from 0.5 to 8
tooltip = 
manpage = Sigma beta (in pixels) for Gaussian smoothing of regions above threshold
during diffusion iterations.  Typical values are from 0.5 to 8; the default is
0.5 and not very useful.

[Field = Tau]
short = t
type = FA
usage = Tau (threshold value), typical values from  0.1 to 0.2
tooltip = 
manpage = Tau, the threshold fraction of the maximum gradient for regions to
be smoothed.  Typical values are from 0.1 to 0.2; the default is 0.1.
