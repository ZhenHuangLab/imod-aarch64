[Field = RobustFitCriterion]
short = robust
type = F
usage = Criterion for ignoring aberrant edge shifts when finding piece shifts
tooltip =
manpage = When solving for the piece shifts from the displacements between
pieces, Blendmont(1) can give less weight to, or completely ignore,
displacements that appear to be outliers.  This option activates this
robust fitting and specifies the criterion for determining an outlier.  A
value of 1 will generally find nearly all outliers but may downweight some edge
displacements inappropriately and give a poor blend across those edges.
Higher values, up to about 1.5, will avoid the latter problem but will tend
not to catch actual outliers.  This option is ideal for getting a higher
quality blend quickly for a low-magnification map where grid bars ruin some of
the displacements.  For data to be analyzed, it is preferable to fix the bad
displacements or mark edges to be excluded in Midas(1).
Robust fitting is available only with more than 10 pieces.

[Field = ParallelBlend]
short = parallel
type = I
usage = Use parallel blending of individual files; assume given # of processors
tooltip = 
manpage = This option causes the program to run Blendmont(1) in parallel for
each individual input file.  Splitblend(1) is called with the given number as
the expected number of processors.  If \fB-cpus\fR is not entered,
Processchunks(1) is run with the same number of processors; however, if
\fB-cpus\fR is entered, it will be sent to Processchunks(1) and that
determines how many processors are actually used.  It is best to make the
number of processors be consistent between the two entries.

[Field = CheckFile]
short = check
type = FN
usage = File to check for quit and finish signals
tooltip = 
manpage = File to check for quit and finish signals.  The default is 
"justblend.cmds" in the directory where this program is run.
This file should not have the same name as the file used to
control Processchunks(1) when it runs jobs, which is "processchunks-jb.cmds", also
in the current directory.
If a Q is placed in this file, it will terminate any
running jobs and stop all processing.  If an F is placed in the file, the
program will stop after finishing the current file.  A P can be used instead
of F except when blending individual files in parallel.
