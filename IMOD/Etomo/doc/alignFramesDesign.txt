  <The first two toggle each other, the third is independent, but what happens
  when "angles in filenames" is selected
  depends on whether one of the others is checked.  If neither of the first
  two are checked, this is referred to as "just angles in filenames"
  When matching tilt series or text files is checked, the goal is to get the input files
  in the same order as the tilt series or those tilt angles.  This is done by running
  sorttiltframes, which returns a list of the input files in the right order:
   run sorttiltframes with
       TiltSeriesFile  stackname   OR   TiltAngleFile  anglefile
       ListOfInputFiles  listFileFromUser OR rootname_templist.txt
           (the file list is one filename per line in the order they were selected)
       Delimiters  se     (the starting and ending delimiter characters)
       OutputFileList  rootname_inlist.txt
   and that output file would be given to alignframes with ListOfInputFiles
   and Etomo has to make rootname_templist.txt from browser-selected files

  When neither tilt series nor angles is checked (just angles in names), the goal is
  to tell aignframes the tilt angles in same order as the list of files:
    run sorttiltframes with
       ListOfInputFiles  listFileFromUser OR rootname_inlist.txt
       Delimiters  se
       UnsortedOutput 1
       OutputTiltAngleFile   rootname_matching.tlt

           PLUS if dose weighting with fixed dose is selected below
       FixedImageDose   fixedDose
       DoseOutputFile   rootname_dose.txt
